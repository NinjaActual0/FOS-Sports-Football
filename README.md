# FOS Sports Football

A physics-driven, real-time American football game. No dice-rolling, no scripted outcomes. 
Every action is determined by real physics, player measurables from combine numbers, environmental conditions, equipment, health, and user input.

## Philosophy
- **Physics over RNG**: Outcomes come from momentum, angles, leverage, velocity, timing, positioning.
- **Measurables matter**: Attributes are derived from real combine/measurable data (40, 10-split, vertical, broad, 3-cone, shuttle, weight, height, wingspan, etc.).
- **Environment matters**: Weather, field conditions (grass/turf/wet/mud/snow/ice), temperature, wind, altitude affect play.
- **Equipment matters**: Cleats, gloves, pads, etc affect traction, grip, ball security.
- **Health matters**: Fatigue, injuries, soreness, and wellness directly affect performance in a realistic way.
- **One engine**: Player controlled, Coach Mode (call and watch), and Full Game Simulation all use the exact same physics engine.
- **Simulation + Arcade**: Tuned via physics parameters, not scripted logic.
- **Cross-platform**: Runs on Windows, Linux, macOS, and Steam Deck.
- **Open source**: MIT licensed. Community contributions welcome.
